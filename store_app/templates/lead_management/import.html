Import Rules
  • Rows with the same checkout Name are combined into one lead.
  • Shipping fields are preferred; billing fields are used only when shipping values are empty.
  • Phone values are normalized and country code is stored separately.
  • Products are matched by exact SKU first, then exact product name.
  • Missing line-item products are created automatically and become selectable in Add Lead.
  • Existing checkout IDs are skipped to prevent duplicate leads.
